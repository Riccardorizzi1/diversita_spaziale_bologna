# Diversità Spaziale Urbana - Bologna

Dashboard Streamlit per la visualizzazione della diversità funzionale urbana nel Comune di Bologna.

## Risultati principali

- 7.975 POI classificati
- 542 celle della griglia adattiva
- 8 categorie funzionali
- 6 quartieri
- Moran's I = 0,2250
- p-value = 0,0010
- popolazione 2024 = 392.791 residenti

## Fonti

- OpenStreetMap
- Geofabrik
- Comune di Bologna Open Data

## Avvio

Installare le dipendenze con:

pip install -r requirements.txt

Avviare la dashboard con:

streamlit run app.py
